# PGP Library Interoperability Tests

This directory contains tests for verifying that PGP keys generated by MnemonikeyCs can be successfully imported and used by standard PGP libraries.

## Test Coverage

The `PgpLibraryInteropTests.cs` file includes comprehensive tests for:

1. **Public Key Import** - Verifies armored public keys can be imported
2. **Private Key Import** - Verifies armored private keys can be imported  
3. **Binary Key Import** - Verifies non-armored binary key formats
4. **Subkey Verification** - Ensures all subkeys (encryption, signing, authentication) are preserved
5. **User ID Verification** - Confirms user identity information is correctly encoded
6. **Round-trip Testing** - Validates key data integrity through export/import cycles
7. **Custom Indices** - Tests keys generated with non-default subkey indices

## Test Library

These tests use **BouncyCastle.Cryptography**, the industry-standard cryptographic library for .NET, to verify PGP compatibility.

## Current Status

✅ **All Tests Passing** - Ed25519 key encoding issues have been resolved! Keys generated by MnemonikeyCs are now fully compatible with standard PGP libraries.

### Fixed Issues

The following encoding issues have been fixed:

1. **Ed25519 OID Encoding** - Added the Ed25519 OID (1.3.6.1.4.1.11591.15.1) before the MPI-encoded public key
2. **EdDSA Point Prefix** - Added the required 0x40 prefix to EdDSA public key points before MPI encoding
3. **Signature Encoding** - Ed25519 signatures are now properly encoded as two separate MPIs (R and S values) instead of a single byte array
4. **Fingerprint Calculation** - Updated to include the OID and 0x40 prefix for accurate key identification

These fixes ensure compliance with RFC 4880bis Section 5.5.5 for EdDSA key packet format.

## Running Tests

```bash
# Run all PGP interop tests
dotnet test --filter "FullyQualifiedName~PgpLibraryInteropTests"

# Run specific test
dotnet test --filter "FullyQualifiedName~PgpLibraryInteropTests.ImportPublicKey_WithBouncyCastle"
```

All 9 tests should pass, confirming full interoperability with standard PGP implementations.

## Purpose

These tests ensure that:
- Keys generated by MnemonikeyCs follow OpenPGP standards
- The generated keys are compatible with other PGP implementations
- Users can export keys from MnemonikeyCs and import them into standard PGP tools (GPG, Kleopatra, etc.)
- Keys can be successfully parsed and validated by BouncyCastle
