# PGP Interoperability Tests

This directory contains tests that verify MnemonikeyCs-generated keys work correctly with various PGP implementations.

## Test Files

### PgpLibraryInteropTests.cs ✅
Tests interoperability with BouncyCastle PGP library (C#). All tests passing.

**Coverage:**
- Imports public and private keys (armored and binary)
- Verifies key structure (master + 3 subkeys)
- Validates user IDs
- Tests fingerprint calculation
- Round-trip key export/import
- Custom subkey indices

**Status:** ✅ **ALL 9 TESTS PASSING**

### GpgInteropTests.cs ✅
Tests interoperability with GPG command-line tool (actual PGP implementation).

**Coverage:**
- Imports keys into GPG keyring
- Encrypts messages with public key
- Decrypts messages with private key
- Full encryption/decryption round-trip

**Status:** ✅ **BOTH TESTS PASSING** (when GPG is available)

## Test Approach

Inspired by the Go mnemonikey reference implementation which uses actual GPG import for validation, our tests include both library-based (BouncyCastle) and command-line (GPG) verification to ensure maximum compatibility.

## Historical Issues (RESOLVED)

### Ed25519 Key Encoding Issues ✅ FIXED

The following encoding issues have been fixed:

1. **Ed25519 OID Encoding** - Added the Ed25519 OID (1.3.6.1.4.1.11591.15.1) before the MPI-encoded public key
2. **EdDSA Point Prefix** - Added the required 0x40 prefix to EdDSA public key points before MPI encoding
3. **Signature Encoding** - Ed25519 signatures are now properly encoded as two separate MPIs (R and S values) instead of a single byte array
4. **Fingerprint Calculation** - Updated to include the OID and 0x40 prefix for accurate key identification

**Technical Details:**
- Ed25519 OID: `{0x2B, 0x06, 0x01, 0x04, 0x01, 0xDA, 0x47, 0x0F, 0x01}` (9 bytes)
- EdDSA point prefix: `0x40` byte before the 32-byte public key
- Signature format: 64-byte Ed25519 signature split into two 32-byte MPIs

These fixes ensure compliance with RFC 4880bis Section 5.5.5 for EdDSA key packet format.

## Running Tests

```powershell
# Run only BouncyCastle tests
dotnet test --filter "FullyQualifiedName~PgpLibraryInteropTests"

# Run only GPG tests (requires GPG installed)
dotnet test --filter "FullyQualifiedName~GpgInteropTests"

# Run all PGP tests
dotnet test --filter "FullyQualifiedName~Pgp"
```

## Dependencies

- **BouncyCastle.Cryptography** 2.6.2 - For PgpLibraryInteropTests
- **GPG** (optional) - For GpgInteropTests (tests are skipped if GPG not available)

## Purpose

These tests ensure that:
- Keys generated by MnemonikeyCs follow OpenPGP standards
- The generated keys are compatible with other PGP implementations
- Users can export keys from MnemonikeyCs and import them into standard PGP tools (GPG, Kleopatra, etc.)
- Keys can be successfully parsed and validated by BouncyCastle
